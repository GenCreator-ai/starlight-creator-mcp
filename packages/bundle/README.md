# starlight-creator-mcp

Sovereign creator MCP: BYOK image/video/audio generation, taste scoring, provenance ledger and human-gated publishing on your own machine. The substrate brand packs build on.

The installable bundle. See the [repository README](https://github.com/frankxai/starlight-creator-mcp) for install and usage.

Part of the [Starlight creator substrate](https://github.com/frankxai/starlight-creator-mcp). BYOK and local-first: provider keys stay in the user's OS keychain and generated media stays on their machine.
